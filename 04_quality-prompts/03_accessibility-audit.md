# アクセシビリティ監査

> **カテゴリ**: 品質管理
> **前提**: React + TypeScript + TailwindCSS + アトミックデザイン
> **難易度**: ★★★☆☆
> **所要時間目安**: 30〜45分

## このプロンプトの使い方

WCAG 2.1 AA 準拠を目標として、アプリケーション全体のアクセシビリティを監査する際に使用します。

---

## プロンプト

````text
以下のチェックリストに基づき、プロジェクトのアクセシビリティ（a11y）監査を実施してください。
問題を検出した場合は修正してください。WCAG 2.1 AA レベルの準拠を目標とします。

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
■ 1. セマンティック HTML
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
- [ ] 見出し（h1〜h6）が適切な階層構造になっていること
- [ ] ページごとに h1 が1つだけ存在すること
- [ ] ナビゲーションに <nav> 要素を使用していること
- [ ] メインコンテンツに <main> 要素を使用していること
- [ ] フッターに <footer> 要素を使用していること
- [ ] リストに <ul>/<ol>/<li> を使用していること
- [ ] ボタンに <button> を使用していること（div onClick は NG）
- [ ] リンクに <a> を使用していること

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
■ 2. キーボード操作
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
- [ ] すべてのインタラクティブ要素が Tab でフォーカス可能であること
- [ ] Tab 順序が視覚的な順序と一致していること
- [ ] Enter / Space でボタン・リンクが動作すること
- [ ] ESC でモーダル・ドロップダウンが閉じること
- [ ] フォーカスインジケーターが常に視認可能であること（ring-2 等）
- [ ] フォーカストラップがモーダル内で正しく動作すること
- [ ] スキップリンク（「メインコンテンツへ」）が存在すること

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
■ 3. ARIA
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
- [ ] aria-label が必要な要素に設定されていること（アイコンボタン等）
- [ ] aria-labelledby / aria-describedby が適切に使用されていること
- [ ] aria-live="polite" が動的コンテンツ更新に使用されていること
- [ ] role 属性が正しく設定されていること
- [ ] aria-hidden="true" が装飾的アイコンに設定されていること
- [ ] aria-expanded がアコーディオン・ドロップダウンに設定されていること
- [ ] aria-current="page" がアクティブなナビゲーションに設定されていること

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
■ 4. 色とコントラスト
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
- [ ] テキストのコントラスト比が 4.5:1 以上であること（AA 基準）
- [ ] 大きなテキスト（18px bold / 24px）のコントラスト比が 3:1 以上であること
- [ ] 色だけで情報を伝えていないこと（アイコン・テキストを併用）
- [ ] ダークモードでもコントラスト比が確保されていること
- [ ] フォーカスインジケーターが背景色に対して視認可能であること

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
■ 5. フォーム
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
- [ ] すべての入力フィールドに <label> が関連付けられていること
- [ ] 必須フィールドに aria-required="true" が設定されていること
- [ ] エラーメッセージが aria-describedby で入力フィールドに関連付けられていること
- [ ] エラー状態が aria-invalid="true" で伝えられていること
- [ ] フォーム送信のフィードバックがスクリーンリーダーに通知されること

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
■ 6. 画像とメディア
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
- [ ] すべての画像に意味のある alt テキストがあること
- [ ] 装飾的な画像に alt="" が設定されていること
- [ ] アイコンのみのボタンに aria-label があること

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
■ 7. レスポンシブ・ズーム
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
- [ ] 200% ズームでもレイアウトが崩れないこと
- [ ] テキストが相対単位（rem, em）で指定されていること
- [ ] ピンチズームが無効化されていないこと

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
````
