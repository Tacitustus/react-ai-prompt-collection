# コードレビューチェックリスト

> **カテゴリ**: 品質管理
> **前提**: React + TypeScript + TailwindCSS + アトミックデザイン
> **難易度**: ★★☆☆☆
> **所要時間目安**: 15〜30分

## このプロンプトの使い方

コード変更後にAIエージェントにコードレビューを依頼する際に使用します。変更対象のファイルパスを指定して渡してください。

---

## プロンプト

````text

各項目について ✅（OK）/ ❌（要修正）/ ⚠️（要検討）で評価し、❌ の項目には改善案を具体的に提示してください。

- [ ] unknown + 型ガードで安全にキャストしていること
- [ ] 関数の引数・戻り値に型が明示されていること
- [ ] ジェネリクスが適切に使用されていること
- [ ] 型アサーション（as）の使用が最小限であること
- [ ] null / undefined の安全な処理（オプショナルチェーン、Nullish Coalescing）
- [ ] ユニオン型の網羅性チェック（switch の default / exhaustive check）

■ 2. コーディング規約
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
- [ ] すべての関数がアロー関数であること
- [ ] JSDoc がコンポーネント・フック・ユーティリティに記述されていること
- [ ] 日本語コメントが処理単位で記述されていること
- [ ] インポート順序が規約に従っていること（React → 外部 → 内部 → 型 → スタイル）
- [ ] パスエイリアス（@/）が使用されていること
- [ ] 命名規約に従っていること（PascalCase / camelCase / UPPER_SNAKE_CASE）

- [ ] コンポーネントが適切な階層に配置されていること
- [ ] atoms が単一責務で、状態を持たないこと（可能な限り）
- [ ] molecules が atoms の組み合わせであること
- [ ] organisms が適切にカプセル化されていること
- [ ] pages がビジネスロジックを含み、template にレイアウトを委譲していること

- [ ] useEffect の依存配列が正しいこと
- [ ] コンポーネント内で大きなオブジェクトをインラインで生成していないこと
- [ ] 重い計算がレンダリングサイクル外で実行されていること

- [ ] ユーザー入力が適切にサニタイズされていること
- [ ] 機密情報がハードコードされていないこと
- [ ] 環境変数が VITE_ プレフィックスで管理されていること
- [ ] console.log が本番向けコードに残っていないこと

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
- [ ] インタラクティブ要素に適切な role / aria 属性があること
- [ ] 画像に alt 属性があること
- [ ] フォーム要素に label が関連付けられていること
- [ ] キーボード操作が可能であること
- [ ] フォーカスインジケーターが視認可能であること
- [ ] 色だけで情報を伝えていないこと

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
- [ ] 新規コンポーネントに基本的なレンダリングテストがあること
- [ ] エッジケースが考慮されていること
- [ ] テストが読みやすく、意図が明確であること

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

- [ ] レスポンシブデザインが考慮されていること
- [ ] ダークモードで正しく表示されること
- [ ] ローディング状態が適切に表示されること
- [ ] エラー状態が適切に処理されていること
````
