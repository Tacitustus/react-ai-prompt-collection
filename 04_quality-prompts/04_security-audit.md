# セキュリティ監査

> **カテゴリ**: 品質管理
> **前提**: React + TypeScript + TailwindCSS + アトミックデザイン
> **難易度**: ★★★★☆
> **所要時間目安**: 30〜45分

## このプロンプトの使い方

フロントエンドのセキュリティを包括的に監査する際に使用します。XSS、CSRF、機密情報漏洩、依存関係の脆弱性等をチェックします。

---
