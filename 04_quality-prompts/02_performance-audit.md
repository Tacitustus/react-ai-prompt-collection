# パフォーマンス監査

> **カテゴリ**: 品質管理
> **前提**: React + TypeScript + TailwindCSS + アトミックデザイン
> **難易度**: ★★★★☆
> **所要時間目安**: 30〜60分

## このプロンプトの使い方

Webアプリのパフォーマンスを包括的に監査し、改善を実施する際に使用します。Lighthouse スコアの分析から具体的な最適化までをカバーします。

---

## プロンプト

````text
以下の項目に基づき、プロジェクトのパフォーマンス監査を実施してください。
問題を検出した場合は、具体的な改善案とコード例を提示し、修正してください。

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
■ 1. バンドルサイズ分析
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
- npm run build を実行し、バンドルサイズを確認する
- rollup-plugin-visualizer（未導入の場合は追加）でバンドル構成を可視化する
- 大きな依存関係を特定し、軽量な代替策を提案する
- Tree-shaking が正しく動作しているか確認する
- 不要な依存関係がバンドルに含まれていないか確認する

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
■ 2. コード分割
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
- React.lazy + Suspense でページ単位のコード分割が行われているか確認
- 重いコンポーネント（チャート、エディタ等）が動的インポートされているか
- 初回ロードに不要なコードが含まれていないか

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
■ 3. レンダリング最適化
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
- React DevTools Profiler で不要な再レンダリングを特定する
- 以下を確認・修正:
  - props として新しいオブジェクト/配列がレンダリングごとに生成されていないか
  - コールバック関数がレンダリングごとに新しい参照を持っていないか
  - useEffect の依存配列が正しいか（不足/過剰）
  - Zustand の selector パターンが適切に使われているか
  - key prop が安定しているか（index の使用を避ける）

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
■ 4. 画像最適化
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
- 画像が WebP / AVIF 形式に変換されているか
- loading="lazy" が適用されているか（ファーストビュー外の画像）
- width / height が明示されているか（CLS 防止）
- 適切なサイズの画像が配信されているか（srcset / sizes）

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
■ 5. フォント最適化
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
- font-display: swap が設定されているか
- プリロード（<link rel="preload">）が適用されているか
- 使用していないフォントウェイトが含まれていないか
- セルフホスティング vs CDN の最適な選択がされているか

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
■ 6. API / データ取得最適化
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
- TanStack Query の staleTime / gcTime が適切か
- 不要な API コールが発生していないか
- プリフェッチが活用されているか
- ウォーターフォール問題がないか（直列の API コール）

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
■ 7. CSS 最適化
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
- 未使用の CSS が PurgeCSS（TailwindCSS 内蔵）で除去されているか
- CSS アニメーションが GPU アクセラレーション（transform, opacity）を使用しているか
- レイアウトシフトを引き起こす CSS がないか

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
■ 報告形式
````
