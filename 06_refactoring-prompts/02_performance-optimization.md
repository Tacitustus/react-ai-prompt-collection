# パフォーマンス最適化

> **カテゴリ**: リファクタリング
> **前提**: React + TypeScript + TailwindCSS + アトミックデザイン
> **難易度**: ★★★★☆
> **所要時間目安**: 30〜60分

## このプロンプトの使い方

React アプリケーションのパフォーマンスを最適化する際に使用します。レンダリング最適化、メモ化、コード分割、画像最適化等を包括的に行います。

---

## プロンプト

````text
以下のガイドラインに従い、プロジェクトのパフォーマンス最適化を実施してください。
既存の AGENTS.md および BLUEPRINT.md の規約に従ってください。

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
■ 1. レンダリング最適化
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

### React.memo
以下の条件に該当するコンポーネントに React.memo を適用する：
- 親が頻繁に再レンダリングされるが、自身の Props は変わらない
- リストアイテムコンポーネント
- 重い計算やDOM操作を含むコンポーネント

### useMemo
以下のケースで適用する：
- 配列のフィルタリング・ソート・マッピング（データ量が多い場合）
- オブジェクトの生成（Props として渡す場合）
- 複雑な計算処理

### useCallback
以下のケースで適用する：
- React.memo されたコンポーネントに渡すコールバック
- useEffect の依存配列に含まれるコールバック
- カスタムフックが返すコールバック

### 注意: 過剰なメモ化を避ける
- 軽量な計算にはメモ化しない
- Props が毎回変わるコンポーネントにはメモ化しない
- メモ化のコスト > 再計算のコストの場合は使用しない

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
■ 2. コード分割
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
- ページ単位で React.lazy + Suspense を適用する
- 重いライブラリ（チャート、エディタ、マップ等）を動的インポートする
- Suspense のフォールバックにスケルトンUIを使用する
- プリロード（preload / prefetch）を活用する

```typescript
// ルーティングでの遅延ロード
const DashboardPage = lazy(() => import('@/components/pages/DashboardPage'));

// 重いコンポーネントの動的インポート
const ChartWidget = lazy(() => import('@/components/organisms/ChartWidget'));
```

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
■ 3. 画像最適化
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
- loading="lazy" を非ファーストビュー画像に適用
- width / height を明示して CLS を防止
- WebP / AVIF フォーマットの使用を検討
- srcset による解像度ごとの画像提供
- アイコンは SVG を使用（lucide-react）

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
■ 4. 仮想スクロール
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
大量のリストアイテム（100件以上）がある場合:
- @tanstack/react-virtual の導入を検討
- ウィンドウ内の要素のみをレンダリング

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
■ 5. Zustand セレクター最適化
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
- 必要な値のみを selector で取得する
- useShallow を活用する
- selector が新しい参照を返さないようにする

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
■ 6. TanStack Query 最適化
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
- staleTime を適切に設定（頻繁に変わらないデータは長めに）
- select オプションで必要なデータのみを返す
- placeholderData でローディング時のちらつきを防止
- プリフェッチを活用する

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
■ コーディング規約
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
- AGENTS.md のコーディング規約をすべて遵守する
- 最適化の理由をコメントに記述する

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
■ タスク完了時
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
AGENTS.md の「タスク完了時の確認事項」に従い報告してください。
追加で、最適化前後の比較も報告すること。
````
