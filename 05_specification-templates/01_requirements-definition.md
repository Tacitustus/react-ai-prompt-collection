# 要件定義書テンプレート

> **カテゴリ**: 仕様書テンプレート
> **前提**: React + TypeScript + TailwindCSS + アトミックデザイン
> **難易度**: ★★★☆☆
> **所要時間目安**: 30〜60分（AIエージェントとの対話含む）

## このプロンプトの使い方

プロジェクト開始時に、AIエージェントに以下のプロンプトを渡して要件定義書を作成してもらいます。
「概要」セクションにプロジェクトの簡単な説明を入力してから渡すと、より精度の高い要件定義書が生成されます。

## カスタマイズポイント

| 箇所 | 説明 |
|------|------|
| ペルソナ | プロジェクトに合わせてペルソナ数を増減する |
| 優先度付け | MoSCoW 法以外（例: RICE スコア）を使う場合はテンプレートを変更 |
| 非機能要件 | Lighthouse 目標値はプロジェクトの性質に合わせて調整 |
| ブラウザ対応 | IE11 対応が必要な場合はポリフィル戦略を追記 |
