# 国際化対応（i18n）

> **カテゴリ**: 機能追加
> **前提**: React + TypeScript + TailwindCSS + アトミックデザイン
> **難易度**: ★★★☆☆
> **所要時間目安**: 30〜45分

## このプロンプトの使い方

react-i18next を使ったプロジェクトの多言語対応を行う際に使用します。

---

## プロンプト

````text
以下の仕様に従い、react-i18next による国際化（i18n）を導入してください。
既存の AGENTS.md および BLUEPRINT.md の規約に従ってください。

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
■ 追加パッケージ
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
- i18next
- react-i18next
- i18next-browser-languagedetector（ブラウザ言語の自動検出）
- i18next-http-backend（翻訳ファイルの動的ロード、オプション）

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
■ 対応言語
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
- 日本語（ja）: デフォルト言語
- 英語（en）

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
■ 構成ファイル
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```
src/
├── i18n/
│   ├── config.ts              # i18n 初期化設定
│   ├── types.ts               # 翻訳キーの型定義
│   └── locales/
│       ├── ja/
│       │   ├── common.json    # 共通（ボタン、ラベル等）
│       │   ├── auth.json      # 認証関連
│       │   ├── errors.json    # エラーメッセージ
│       │   ├── validation.json # バリデーションメッセージ
│       │   └── pages/
│       │       ├── home.json
│       │       └── dashboard.json
│       └── en/
│           ├── common.json
│           ├── auth.json
│           ├── errors.json
│           ├── validation.json
│           └── pages/
│               ├── home.json
│               └── dashboard.json
├── components/
│   └── molecules/
│       └── LanguageSwitcher.tsx # 言語切り替えUI
├── hooks/
│   └── useTranslation.ts       # 型安全な翻訳フック（オプション）
```

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
■ 名前空間（namespace）分割
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
翻訳キーは名前空間で分割して管理する：
- `common`: 共通テキスト（ボタン: 保存、キャンセル、送信 等）
- `auth`: 認証関連テキスト
- `errors`: エラーメッセージ
- `validation`: バリデーションメッセージ
- `pages/*`: ページ固有のテキスト

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
■ 翻訳ファイルの例
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```json

{
  "button": {
    "save": "保存",
    "cancel": "キャンセル",

  }
}
```

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
■ 言語切り替え UI
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
- ドロップダウンまたはトグルボタン
- 国旗アイコン + 言語名
- 選択した言語を localStorage に永続化
- html の lang 属性を自動更新
- ダークモード対応
- Header コンポーネント内に配置

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
■ 日付・数値のフォーマット
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
- Intl.DateTimeFormat / Intl.NumberFormat を言語設定と連動させる
- ユーティリティ関数として formatDate, formatNumber, formatCurrency を提供

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
■ コーディング規約
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
- AGENTS.md のコーディング規約をすべて遵守する
- ハードコードされた日本語テキストは許可しない（すべて翻訳キー経由）
- 翻訳キーは TypeScript で型チェックする
- any 禁止、アロー関数、JSDoc、日本語コメント

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
■ タスク完了時
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
AGENTS.md の「タスク完了時の確認事項」に従い、すべてのチェックを実施して報告してください。
````

## カスタマイズポイント

| 箇所 | 説明 |
|------|------|
| 対応言語 | 中国語、韓国語等を追加可能 |
| 動的ロード | 翻訳ファイルを遅延ロードする場合は i18next-http-backend を使用 |
| 名前空間 | プロジェクトの機能に合わせて追加 |
| RTL対応 | アラビア語等のRTL言語を含む場合は dir 属性の切り替えを追加 |
