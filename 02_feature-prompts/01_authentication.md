# 認証機能

> **カテゴリ**: 機能追加
> **前提**: React + TypeScript + TailwindCSS + アトミックデザイン
> **難易度**: ★★★★☆
> **所要時間目安**: 60〜90分

## このプロンプトの使い方

プロジェクトに認証機能（ログイン・サインアップ・ログアウト・パスワードリセット）を追加する際に使用します。「カスタマイズポイント」で認証プロバイダ（Firebase / Supabase / Auth0 / 自前API）を指定してください。

---

## プロンプト

````text

既存の AGENTS.md および BLUEPRINT.md の規約に従ってください。

■ 認証プロバイダ
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
【ここに認証プロバイダを指定: Firebase Auth / Supabase Auth / Auth0 / 自前API】

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
1. **メール/パスワード認証**
   - ログイン
   - 新規登録
   - パスワードリセット（メール送信）
   - パスワード変更

2. **ソーシャルログイン**（オプション）
   - Google ログイン
   - GitHub ログイン

3. **認証状態管理**
   - Zustand ストアで認証状態を管理
   - トークンの自動リフレッシュ
   - セッション有効期限の管理

4. **ルートガード**
   - 未認証ユーザーを /login にリダイレクト
   - 認証済みユーザーが /login にアクセスした場合は /dashboard にリダイレクト

5. **UI コンポーネント**
   - ログインフォーム（molecules）
   - 新規登録フォーム（molecules）
   - パスワードリセットフォーム（molecules）
   - ProtectedRoute コンポーネント
   - ユーザーメニュー（organisms: アバター + ドロップダウン）

│   │   ├── ResetPasswordForm.tsx

│   ├── stores/

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
■ フォームバリデーション
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
React Hook Form + Zod を使用し、以下のバリデーションを実装すること：

### ログイン
- メール: 必須、メール形式
- パスワード: 必須、8文字以上

### 新規登録
- 名前: 必須、2〜50文字
- メール: 必須、メール形式
- パスワード: 必須、8文字以上、大文字小文字数字を含む
- パスワード確認: パスワードと一致

### パスワードリセット
- メール: 必須、メール形式

- 認証ページ専用のレイアウト（AuthLayout: 中央寄せ、グラデーション背景）
- グラスモーフィズムのカードデザイン
- パスワード表示/非表示トグル
- バリデーションエラーのリアルタイム表示
- ローディング状態のボタンアニメーション
- ソーシャルログインボタン（アイコン付き）
- レスポンシブ対応（モバイルファースト）

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
■ セキュリティ
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
- パスワードをフロントエンドで平文保存しない
- トークンは httpOnly Cookie または Zustand + persist で管理
- CSRF 対策を考慮
- ログイン試行回数の制限（UI側のレート制限表示）
````
