# 無限スクロール＆ページネーション

> **カテゴリ**: 機能追加
> **前提**: React + TypeScript + TailwindCSS + アトミックデザイン
> **難易度**: ★★★☆☆
> **所要時間目安**: 25〜40分

## このプロンプトの使い方

一覧データの表示に無限スクロールまたはページネーションを実装する際に使用します。TanStack Query の useInfiniteQuery と Intersection Observer を組み合わせます。

---

## プロンプト

````text
以下の仕様に従い、無限スクロールとページネーションの両方に対応した一覧表示システムを構築してください。
既存の AGENTS.md および BLUEPRINT.md の規約に従ってください。

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
■ 構成ファイル
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```
src/
├── components/
│   ├── atoms/
│   │   ├── Skeleton.tsx             # スケルトンローディング
│   │   └── Spinner.tsx              # ローディングスピナー
│   ├── molecules/
│   │   ├── Pagination.tsx           # 番号付きページネーション
│   │   ├── LoadMoreTrigger.tsx      # 無限スクロールトリガー
│   │   └── EmptyState.tsx           # 空状態コンポーネント
│   └── organisms/
│       └── InfiniteList.tsx         # 無限スクロールリスト（汎用）
├── hooks/
│   ├── useInfiniteScroll.ts         # 無限スクロールフック
│   ├── usePagination.ts            # ページネーションフック
│   └── useIntersectionObserver.ts   # Intersection Observer フック
```

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
■ 無限スクロール
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
- TanStack Query の useInfiniteQuery を使用
- Intersection Observer でリストの末尾を検知して次ページを自動取得
- ローディング中はスピナーを表示
- 全件取得済みの場合は「すべて読み込みました」を表示
- スクロール位置の保持（ブラウザバック時）
- エラー時のリトライボタン

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
■ ページネーション
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
- 番号付きページネーション（1, 2, 3, ..., N）
- 省略表示（1, 2, 3, ..., 8, 9, 10）
- 前へ/次へ ボタン
- 先頭/末尾 ジャンプボタン
- URL クエリパラメータと同期（?page=2）
- ページあたり件数の変更（10, 20, 50）
- 合計件数の表示（「全100件中 1-20件を表示」）

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
■ スケルトンUI
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
- リストアイテムと同じレイアウトのスケルトン
- animate-pulse アニメーション
- 初回ローディング時に表示（件数分）

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
■ 空状態
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
- イラストまたはアイコン
- 説明テキスト
- CTA ボタン（「最初のアイテムを作成」等）

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
■ コーディング規約
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
- AGENTS.md のコーディング規約をすべて遵守する
- any 禁止、ジェネリクスで型安全に
- アロー関数、JSDoc、日本語コメント

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
■ タスク完了時
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
AGENTS.md の「タスク完了時の確認事項」に従い、すべてのチェックを実施して報告してください。
````
