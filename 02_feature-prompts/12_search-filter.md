# 検索＆フィルタリング

> **カテゴリ**: 機能追加
> **前提**: React + TypeScript + TailwindCSS + アトミックデザイン
> **難易度**: ★★★☆☆
> **所要時間目安**: 25〜40分

## このプロンプトの使い方

デバウンス付きのリアルタイム検索、ファセットフィルター、URL同期を実装する際に使用します。

---

## プロンプト

````text
以下の仕様に従い、検索＆フィルタリング機能を構築してください。
既存の AGENTS.md および BLUEPRINT.md の規約に従ってください。

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
■ 構成ファイル
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```
src/
├── components/
│   ├── atoms/
│   │   └── SearchInput.tsx          # 検索入力（虫眼鏡アイコン + クリアボタン）
│   ├── molecules/
│   │   ├── FilterChip.tsx           # フィルターチップ（選択済みフィルターの表示）
│   │   ├── FilterDropdown.tsx       # フィルタードロップダウン
│   │   ├── FilterGroup.tsx          # フィルターグループ（チェックボックス一覧）
│   │   ├── SortSelect.tsx           # ソート選択
│   │   └── ActiveFilters.tsx        # アクティブフィルター一覧 + クリアボタン
│   └── organisms/
│       ├── SearchFilterBar.tsx      # 検索 + フィルター + ソートを統合
│       └── FilterSidebar.tsx        # サイドバー型フィルター（デスクトップ）
├── hooks/
│   ├── useSearch.ts                 # 検索フック（デバウンス付き）
│   ├── useFilters.ts               # フィルター管理フック
│   ├── useSortOrder.ts             # ソート管理フック
│   └── useSearchParams.ts          # URL クエリパラメータ同期フック
```

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
■ 検索
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
- デバウンス検索（300ms）: useDebounce フックと連携
- 検索キーワードのハイライト表示
- 検索結果件数の表示
- クリアボタン（×アイコン）
- 空文字で全件表示
- URL パラメータとの同期（?q=検索キーワード）
- Ctrl+K / Cmd+K でフォーカス

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
■ フィルタリング
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
- ファセットフィルター（カテゴリ、ステータス、タグ等）
- チェックボックス型の複数選択
- フィルターチップで選択済み条件を視覚化
- 個別解除 / 全解除
- URL パラメータとの同期（?status=active&category=tech）
- フィルター数のバッジ表示

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
■ ソート
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
- ソートフィールド選択（作成日、更新日、名前等）
- 昇順/降順の切り替え
- URL パラメータとの同期（?sort=createdAt&order=desc）

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
■ レスポンシブ対応
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
- デスクトップ: サイドバー型フィルター + 検索バー
- モバイル: ドロワー型フィルター（「フィルター」ボタンで開閉）

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
■ コーディング規約
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
- AGENTS.md のコーディング規約をすべて遵守する
- any 禁止、アロー関数、JSDoc、日本語コメント

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
■ タスク完了時
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
AGENTS.md の「タスク完了時の確認事項」に従い、すべてのチェックを実施して報告してください。
````
