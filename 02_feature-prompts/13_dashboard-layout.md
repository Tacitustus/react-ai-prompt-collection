# ダッシュボードレイアウト

> **カテゴリ**: 機能追加
> **前提**: React + TypeScript + TailwindCSS + アトミックデザイン
> **難易度**: ★★★★☆
> **所要時間目安**: 40〜60分

## このプロンプトの使い方

管理画面やダッシュボードのレイアウトを構築する際に使用します。サイドバーナビゲーション、統計カード、チャートを含みます。

---

## プロンプト

````text
以下の仕様に従い、ダッシュボードレイアウトを構築してください。
既存の AGENTS.md および BLUEPRINT.md の規約に従ってください。

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
■ 追加パッケージ
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
- recharts（チャートライブラリ）

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
■ 構成ファイル
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```
src/
├── components/
│   ├── atoms/
│   │   ├── StatValue.tsx            # 統計値表示
│   │   ├── TrendIndicator.tsx       # トレンドインジケーター（↑↓%）
│   │   └── SidebarNavItem.tsx       # サイドバーナビアイテム
│   ├── molecules/
│   │   ├── StatCard.tsx             # 統計カード（アイコン + 値 + トレンド）
│   │   ├── ChartCard.tsx            # チャートカード（タイトル + チャート）
│   │   ├── SidebarNavGroup.tsx      # サイドバーナビグループ（折りたたみ）
│   │   └── Breadcrumb.tsx           # パンくずリスト
│   ├── organisms/
│   │   ├── Sidebar.tsx              # サイドバーナビゲーション
│   │   ├── DashboardHeader.tsx      # ダッシュボードヘッダー
│   │   ├── StatCardGrid.tsx         # 統計カードグリッド
│   │   ├── LineChartWidget.tsx      # 折れ線グラフウィジェット
│   │   ├── BarChartWidget.tsx       # 棒グラフウィジェット
│   │   ├── PieChartWidget.tsx       # 円グラフウィジェット

│   ├── templates/
│   │   └── DashboardLayout.tsx      # ダッシュボードレイアウト
│   └── pages/
│       └── DashboardPage.tsx        # ダッシュボードページ
├── stores/
│   └── useUIStore.ts                # サイドバー開閉状態
```

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
■ レイアウト構成
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```
┌─────────────────────────────────────────┐
│ Sidebar │       DashboardHeader        │

│  Logo   │  Breadcrumb                  │
│  ──────│                               │
│  Menu1  │  ┌──────┐ ┌──────┐ ┌──────┐ │
│  Menu2  │  │Stat1 │ │Stat2 │ │Stat3 │ │

│  Group  │  ┌──────────────┐ ┌────────┐│
│  Menu4  │  │  Line Chart  │ │  Pie   ││
│  Menu5  │  │              │ │ Chart  ││
│         │  └──────────────┘ └────────┘│
│  ──────│                               │
│  Bottom │  ┌──────────────────────────┐│

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
■ サイドバー
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
- 折りたたみ可能（アイコンのみ表示）
- ナビグループ（セクション区切り + 折りたたみ）
- アクティブ状態のハイライト
- ユーザー情報（アバター + 名前）をボトムに表示
- モバイルではオーバーレイ + ハンバーガーメニュー
- アニメーション: 幅の変化に transition

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
■ 統計カード
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
- アイコン（lucide-react）
- 主要指標値（大きなフォント）
- 前期比のトレンド（↑12% 緑 / ↓3% 赤）
- ホバーアニメーション
- グラデーション背景 or 左側カラーバー

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
■ チャート（Recharts）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
- レスポンシブ（ResponsiveContainer）
- ダークモード対応のカラーパレット
- ツールチップ
- 期間切り替え（1週間 / 1ヶ月 / 3ヶ月 / 1年）
- ローディング状態のスケルトン

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
■ レスポンシブ
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
- デスクトップ: サイドバー展開 + グリッドレイアウト
- タブレット: サイドバー折りたたみ + 2カラム
- モバイル: サイドバー非表示（ハンバーガー）+ 1カラム

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
■ コーディング規約
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
- AGENTS.md のコーディング規約をすべて遵守する
- any 禁止、アロー関数、JSDoc、日本語コメント

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
■ タスク完了時
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
AGENTS.md の「タスク完了時の確認事項」に従い、すべてのチェックを実施して報告してください。
````
