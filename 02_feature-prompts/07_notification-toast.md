# トースト通知システム

> **カテゴリ**: 機能追加
> **前提**: React + TypeScript + TailwindCSS + アトミックデザイン
> **難易度**: ★★☆☆☆
> **所要時間目安**: 20〜30分

## このプロンプトの使い方

カスタムのトースト通知（スナックバー）システムを構築する際に使用します。外部ライブラリ（react-hot-toast等）を使わず自前実装するプロンプトです。

---

## プロンプト

````text
以下の仕様に従い、トースト通知システムを自前で構築してください。
既存の AGENTS.md および BLUEPRINT.md の規約に従ってください。

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
■ 構成ファイル
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```
src/
├── stores/
│   └── useNotificationStore.ts   # 通知状態管理（Zustand）
├── components/
│   ├── atoms/
│   │   └── Toast.tsx             # 単一トースト表示
│   └── organisms/
│       └── ToastContainer.tsx    # トースト一覧表示（固定位置）
├── hooks/
│   └── useToast.ts               # トースト操作フック
```

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
■ 機能
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
- 4種類: success（緑）、error（赤）、warning（黄）、info（青）
- 自動消去（デフォルト: 5秒、種類ごとにカスタマイズ可能）
- 手動閉じ（×ボタン）
- スタック表示（最新が上、最大5件）
- 表示位置: 右上（カスタマイズ可能: 左上/右下/左下/中央上/中央下）
- 入場アニメーション: 右からスライドイン + フェードイン
- 退場アニメーション: 右へスライドアウト + フェードアウト
- プログレスバー: 残り時間の視覚表示（下部に細いバー）
- ホバー時: 自動消去を一時停止
- アクションボタン: 「元に戻す」等のアクション対応

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
■ API（使用例）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```typescript
const { toast } = useToast();

// 基本使用
toast.success('保存しました');
toast.error('エラーが発生しました');
toast.warning('入力内容を確認してください');
toast.info('新しい通知があります');

// オプション付き
toast.success('保存しました', {
  duration: 3000,
  action: { label: '元に戻す', onClick: handleUndo },
});
```

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
■ デザイン
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
- 各種類ごとの左側カラーバー
- lucide-react アイコン（CheckCircle, XCircle, AlertTriangle, Info）
- ダークモード対応
- グラスモーフィズム（backdrop-blur + 半透明背景）
- z-index: 最上位（z-50）

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
■ アクセシビリティ
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
- role="alert" で通知をスクリーンリーダーに通知
- aria-live="polite" で非侵入的に読み上げ
- 閉じるボタンに aria-label="通知を閉じる"

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
■ コーディング規約
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
- AGENTS.md のコーディング規約をすべて遵守する
- any 禁止、アロー関数、JSDoc、日本語コメント

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
■ タスク完了時
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
AGENTS.md の「タスク完了時の確認事項」に従い、すべてのチェックを実施して報告してください。
````
