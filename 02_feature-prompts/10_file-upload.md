# ファイルアップロード

> **カテゴリ**: 機能追加
> **前提**: React + TypeScript + TailwindCSS + アトミックデザイン
> **難易度**: ★★★☆☆
> **所要時間目安**: 25〜40分

## このプロンプトの使い方

ドラッグ&ドロップ対応のファイルアップロード機能を構築する際に使用します。画像プレビュー、プログレスバー、バリデーションを含みます。

---

## プロンプト

````text
以下の仕様に従い、ファイルアップロード機能を構築してください。
既存の AGENTS.md および BLUEPRINT.md の規約に従ってください。

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
■ 構成ファイル
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```
src/
├── components/
│   ├── atoms/
│   │   ├── ProgressBar.tsx         # プログレスバー
│   │   └── FileIcon.tsx            # ファイルタイプ別アイコン
│   ├── molecules/
│   │   ├── DropZone.tsx            # ドラッグ&ドロップエリア
│   │   ├── FilePreview.tsx         # ファイルプレビュー（画像サムネイル等）
│   │   └── FileListItem.tsx        # アップロード済みファイル一覧のアイテム
│   └── organisms/
│       └── FileUploader.tsx        # ファイルアップロード全体
├── hooks/
│   ├── useFileUpload.ts            # ファイルアップロードフック
│   └── useDragAndDrop.ts           # ドラッグ&ドロップフック
├── utils/
│   └── fileValidation.ts           # ファイルバリデーション（サイズ、タイプ）
```

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
■ 機能
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
1. **ドラッグ&ドロップ**: ファイルをドロップエリアにドラッグして追加
2. **ファイル選択**: 「ファイルを選択」ボタンでファイルダイアログを開く
3. **複数ファイル対応**: 一度に複数ファイルを選択・アップロード可能
4. **画像プレビュー**: 画像ファイルのサムネイルプレビュー表示
5. **プログレスバー**: アップロード進捗の視覚表示（%表示）
6. **バリデーション**:
   - ファイルサイズ制限（デフォルト: 10MB）
   - 許可するファイルタイプ（MIME type）
   - 最大ファイル数の制限
7. **キャンセル**: アップロード中のキャンセル（AbortController）
8. **リトライ**: 失敗したファイルの再アップロード
9. **削除**: アップロード済み/選択済みファイルの削除

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
■ useFileUpload API
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```typescript
const {
  files,           // アップロードファイル一覧（状態付き）
  addFiles,        // ファイルを追加
  removeFile,      // ファイルを削除
  uploadAll,       // 全ファイルをアップロード
  cancelUpload,    // アップロードをキャンセル
  retryUpload,     // 失敗したファイルをリトライ
  clearAll,        // 全ファイルをクリア
  isUploading,     // アップロード中かどうか
  totalProgress,   // 全体の進捗率 (0-100)
} = useFileUpload({
  maxFileSize: 10 * 1024 * 1024,           // 10MB
  acceptedFileTypes: ['image/*', '.pdf'],
  maxFiles: 5,
  uploadEndpoint: '/api/upload',
  onSuccess: (file) => toast.success(`${file.name} をアップロードしました`),
  onError: (file, error) => toast.error(`${file.name} のアップロードに失敗しました`),
});
```

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
■ DropZone デザイン
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
- 破線ボーダーのエリア
- ドラッグオーバー時: ボーダーが青に変化 + 背景色がハイライト
- アイコン（Upload Cloud）+ テキスト（「ファイルをドラッグ&ドロップ」）
- ダークモード対応
- レスポンシブ対応

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
■ コーディング規約
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
- AGENTS.md のコーディング規約をすべて遵守する
- any 禁止、アロー関数、JSDoc、日本語コメント

■ タスク完了時

AGENTS.md の「タスク完了時の確認事項」に従い、すべてのチェックを実施して報告してください。
````
